# 🍽️ Delicious Bites - Restaurant Menu Web Application

A professional, responsive restaurant menu web page built with HTML and CSS, containerized with Docker, and deployed using Jenkins and Kubernetes.

## Project Overview

Delicious Bites is a modern restaurant menu web application that showcases a restaurant's offerings in an organized, visually appealing manner. The project demonstrates a complete DevOps pipeline from development through containerization to deployment.

### Features

- **Responsive Design**: Mobile-friendly interface that works on all devices
- **Multiple Menu Sections**: Starters, Main Course, Desserts, and Beverages
- **Detailed Menu Items**: Each item includes name, description, and price
- **Professional Styling**: Modern gradient design with smooth animations
- **Complete Contact Information**: Address, phone, email, hours, and social media links
- **Navigation**: Sticky navigation bar for easy section access
- **Docker Support**: Containerized for consistent deployment across environments
- **CI/CD Pipeline**: Jenkins automation for build, test, and deploy workflows
- **Kubernetes Ready**: Deployment configuration for Kubernetes orchestration
